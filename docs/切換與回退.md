# 切換與回退（草稿）

規格階段 5 第 1 項。現況：Dino 自 2026-11-12 起日常使用新版 `adventure.dino.tw`，舊版（claude.ai 上的頁面）的處置尚未決定。

## 一、現況

| 項目 | 狀態 |
|---|---|
| 新版（Cloudflare） | 使用中；同步每 30 分鐘；Access 保護；備份與還原已演練 |
| 舊版（claude.ai 版） | 保留與否、是否還在寫入：**待 Dino 確認** |
| 舊的 `workers.dev` 網址 | 已關閉（2026-11-13 設定，部署後生效） |
| 資料來源 | 同一個 intervals.icu；課表以 intervals.icu 為準，只有「勾選完成」「關鍵標記」「計畫外活動」「範圍設定」是新版自己的資料 |

## 二、建議的切換原則（需 Dino 確認）

1. **只在新版寫入**。舊版不再勾選、不再新增課表，避免兩邊資料不一致。
2. 舊版保留為唯讀，至少再留兩週，不刪除。
3. 兩週內沒有需要回退的狀況，且金鑰輪替已實際做過一次（已做）、備份與還原已演練（已做），就可以正式停用舊版。

## 三、什麼時候回退

出現下列任一情況，回到舊版繼續使用，並通知我處理新版：
- 資料遺失，或勾選的完成狀態對不上。
- 同步連續失敗超過一天，且按「↻」與查看 `/api/sync-status` 仍無法排除。
- Google 登入或 Access 無法登入、而你又需要立刻使用。

## 四、回退流程

1. 先匯出新版資料作為備份：`npx wrangler d1 export adventure --remote --output=backup/rollback-YYYYMMDD.sql`。
2. 在舊版繼續使用。舊版的資料停在切換日，所以切換後新增的資料要補回：
   - 看切換日之後的勾選與計畫外活動：

```bash
npx wrangler d1 execute adventure --remote --command "SELECT date,title,kind,done,done_at FROM workouts WHERE date >= '切換日' ORDER BY date"
```

   - 把結果給我（或貼到舊版的對話），由我協助補回。
3. 問題解決後，從舊版再切回新版前，同樣先確認只在其中一邊寫入。
