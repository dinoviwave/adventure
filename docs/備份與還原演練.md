# 備份與還原演練

目的：確認 D1 的備份能真的還原，並核對筆數一致。備份檔含身體資料，**只放在 `backup/`（已被 .gitignore 排除），不得公開、不得 commit**。
指令依 wrangler 4 的說明整理（`wrangler d1 export --help`、`wrangler d1 time-travel --help`）。

## 一、匯出遠端資料庫（備份）

```bash
mkdir -p backup
```

```bash
npx wrangler d1 export adventure --remote --output=backup/adventure-$(date +%Y%m%d).sql
```

## 二、記下遠端的筆數（正式資料）

（D1 對複合查詢（UNION）的項數有上限，所以這裡用單一查詢加子查詢，不用 UNION。）

```bash
npx wrangler d1 execute adventure --remote --command "SELECT (SELECT count(*) FROM workouts) AS workouts, (SELECT count(*) FROM wellness) AS wellness, (SELECT count(*) FROM config) AS config, (SELECT count(*) FROM checks) AS checks, (SELECT count(*) FROM checkitems) AS checkitems, (SELECT count(*) FROM events) AS events, (SELECT count(*) FROM sync_log) AS sync_log, (SELECT count(*) FROM sync_requests) AS sync_requests"
```

## 三、還原到「本機」的空資料庫（不碰正式資料）

先清掉本機資料庫，再把備份匯入：

```bash
rm -rf .wrangler/state
```

```bash
npx wrangler d1 execute adventure --local --file=backup/adventure-$(date +%Y%m%d).sql
```

## 四、核對本機筆數（應與第二步完全一致）

```bash
npx wrangler d1 execute adventure --local --command "SELECT (SELECT count(*) FROM workouts) AS workouts, (SELECT count(*) FROM wellness) AS wellness, (SELECT count(*) FROM config) AS config, (SELECT count(*) FROM checks) AS checks, (SELECT count(*) FROM checkitems) AS checkitems, (SELECT count(*) FROM events) AS events, (SELECT count(*) FROM sync_log) AS sync_log, (SELECT count(*) FROM sync_requests) AS sync_requests"
```

再抽查內容，例如最近的課表與設定（兩邊結果要一樣）：

```bash
npx wrangler d1 execute adventure --local --command "SELECT id,date,title,done FROM workouts ORDER BY date DESC LIMIT 5"
```

```bash
npx wrangler d1 execute adventure --local --command "SELECT key,value FROM config"
```

## 五、Time Travel（輔助，不取代匯出）

D1 的 Time Travel 免費方案可回溯 7 天（付費 30 天，見《待查證清單》第 3 項）。查看目前的書籤：

```bash
npx wrangler d1 time-travel info adventure
```

**不要在正式資料庫上隨意執行 `time-travel restore`**，它會把正式資料倒回過去的時間點。只有在真的要救資料時才用。

## 七、備份習慣（建議）

- 重大變更前（升級資料庫、改同步規則）先匯出一份。
- 備份檔放在你自己的電腦或私人雲端硬碟，**不要放進 GitHub**。
- 備份檔含身體資料，等同個資，刪除舊備份時一併刪除。
